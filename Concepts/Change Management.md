# Change Management

**Definition:** Change management is a controlled process for planning, approving, testing, implementing and verifying system modifications.

## Key points

- Record business purpose, scope, dependencies, security impact, test results and decision authority.
- Use a tested rollback or safe fail-forward strategy; changes should be observable and traceable.
- Update architecture diagrams, inventory, controls and documentation after deployment.

## AI security example

> [!example] Application
> A revised retrieval-permission policy needs negative access tests before production rollout.
