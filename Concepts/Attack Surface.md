# Attack Surface

**Definition:** An attack surface is the set of externally or internally reachable opportunities an adversary could exploit.

## Key points

- Includes endpoints, APIs, identities, secrets, exposed services, third-party dependencies and management access.
- An attack vector is a particular method or route through that surface.
- Shrink exposure through secure defaults, least privilege, patching, segmentation and inventory.

## AI security example

> [!example] Application
> A model-serving API, vector database, connector and agent tool endpoint each contribute an AI system attack surface.
