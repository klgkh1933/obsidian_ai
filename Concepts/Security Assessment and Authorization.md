# Security Assessment and Authorization

**Definition:** Security assessment and authorization reviews security requirements, implementation, test evidence and residual risk before an accountable authority approves operation or determines required action.

## Key points

- Define system boundaries, assets, stakeholders, sensitivity and expected security controls.
- Collect documented evidence of design, control implementation, test outcomes, gaps and remediation plans.
- Differentiate the assessor who evaluates from the authority who accepts risk; process names and requirements vary by organization.
- Monitor changes, incidents, vulnerabilities and authorization conditions after deployment.

## AI security example

> [!example] Application
> An AI assistant requires evidence of document-level access tests, prompt-injection tests, provider assessment and incident logging before launch.
