# Data Exfiltration

**Definition:** Data exfiltration is unauthorized transfer of information out of an authorized security domain.

## Key points

- Pathways include emails, external APIs, cloud storage, tool calls, logs and model-generated output.
- Strong encryption in transit does not prevent an authenticated application from sending data to the wrong party.
- Apply least privilege, DLP, egress policy, audit trails and data-flow validation.

## AI security example

> [!example] Application
> An AI agent retrieves a protected report and sends it to an attacker-controlled address through an allowed mail connector.
