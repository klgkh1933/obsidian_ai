# AI Data Poisoning

**Definition:** AI data poisoning changes information used by an AI system to influence its behavior, predictions or retrieval results.

## Key points

- Training-time poisoning alters examples, labels or fine-tuning data.
- Retrieval/knowledge-base poisoning alters indexed documents or evidence without retraining model weights.
- Protect provenance, ingestion privileges, labeling quality and evaluation against representative trusted test sets.

## AI security example

> [!example] Application
> A malicious update inserts false policy guidance into a RAG index, influencing answers to internal security questions.
