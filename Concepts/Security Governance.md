# Security Governance

**Definition:** Security governance sets policies, accountabilities, decision authorities and oversight for security risk.

## Key points

- Policy establishes mandatory intent, standard specifies mandatory criteria, procedure explains steps and guideline offers recommendations.
- Assign owners for controls, exceptions, approvals, suppliers and evidence.
- A framework such as NIST CSF helps organize outcomes, but departmental obligations determine applicable controls.

## AI security example

> [!example] Application
> An AI security board defines what an application must demonstrate before processing protected government information.
