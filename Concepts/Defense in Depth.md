# Defense in Depth

**Definition:** Defense in depth uses distinct, independently enforced protective layers so one failure does not cause complete compromise.

## Key points

- Combine controls at identity, application, network, data, monitoring and recovery layers.
- Several controls sharing the same bypass (e.g. one administrator credential) may not be independent.
- Test failure assumptions and control interaction, not simply the number of protections.

## AI security example

> [!example] Application
> Even if retrieved text tricks a model, downstream tool authorization and egress restrictions should still block prohibited actions.
