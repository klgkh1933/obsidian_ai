# Asset Inventory

**Definition:** An asset inventory is an authoritative record of systems, software, data and services, with owners and lifecycle status.

## Key points

- Record identity, version, vendor, network exposure, purpose, classification, support and configuration baseline.
- Reconcile inventory to actual deployed cloud and on-prem resources; discover shadow IT.
- Use inventory to drive scanning, patching, incident response, access review and decommissioning.

## AI security example

> [!example] Application
> Track every LLM model and version, embeddings store, connector, API key, document corpus and agent tool in the AI system.
