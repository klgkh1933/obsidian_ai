# CVE CWE CVSS

**Definition:** CVE, CWE and CVSS describe different parts of the vulnerability-management process.

## Key points

- CVE is a unique public identifier for a disclosed vulnerability.
- CWE is a taxonomy of weakness types (e.g. injection, path traversal).
- CVSS quantifies selected technical severity properties; exposure and mission impact still must be assessed.
- NVD and vendor advisories provide enrichment; source freshness matters.

## AI security example

> [!example] Application
> An API gateway library has a CVE; the underlying CWE is an input-handling issue; the CVSS score is not the complete government-service risk.
