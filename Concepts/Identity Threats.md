# Identity Threats

**Definition:** Identity threats exploit credentials, authenticators, sessions, tokens and permission assignments.

## Key points

- Password spraying and brute force try candidate credentials; phishing can steal login secrets or tokens.
- A stolen session token may remain valid after an MFA step until revoked or constrained.
- Detect anomalous sessions, privilege changes and account lifecycle events; restrict expiry, audience and scopes.

## AI security example

> [!example] Application
> An attacker steals the AI service’s delegated access token and retrieves data despite never knowing a user password.
