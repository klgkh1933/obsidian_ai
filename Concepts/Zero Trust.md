# Zero Trust

**Definition:** Zero Trust is a security architecture that does not confer implicit trust merely because a request originates from an internal network.

## Key points

- Verify each request using identity, context, device/workload status and resource policy.
- Enforce least-privilege access at the protected resource; assume compromise and reduce lateral movement.
- Decision/control plane evaluates policy; enforcement/data plane implements allow/deny. Continuous assessment does not mean constant interactive logins.

## AI security example

> [!example] Application
> A user inside the departmental network still cannot retrieve a document they lack permission to read.
