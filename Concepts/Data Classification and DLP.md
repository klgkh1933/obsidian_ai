# Data Classification and DLP

**Definition:** Data classification assigns handling rules based on information sensitivity; data loss prevention (DLP) detects or restricts unauthorized data movement.

## Key points

- Apply consistent labels, authorized audiences, encryption, retention and disposition requirements.
- Protection must cover stored copies, transmitted data and processing memory, as appropriate.
- DLP can flag email uploads, endpoint copying and API transfers, but requires tuning and does not guarantee prevention of every leak.
- Masking hides fields; tokenization substitutes controlled references; de-identification reduces direct identification but may leave re-identification risk.

## AI security example

> [!example] Application
> Identify protected information in prompts, chunks, vector indexes, retrieved documents, logs and AI output.
