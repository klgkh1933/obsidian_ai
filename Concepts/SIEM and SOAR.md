# SIEM and SOAR

**Definition:** SIEM centralizes, correlates and analyzes security-event records; SOAR orchestrates and automates incident-response workflows.

## Key points

- SIEM: collect, normalize, correlate and alert; calibrate detection and ensure source-feed health.
- SOAR: run governed playbooks for enrichment, containment, ticket creation and restoration.
- Protect logs, service credentials, action audit trails and human authorization for dangerous automated steps.
- False positives create noise; false negatives and missing telemetry can hide harm.

## AI security example

> [!example] Application
> Correlate unusual document retrieval with an agent’s outbound mail tool call; have automation revoke credentials only under reviewed conditions.
