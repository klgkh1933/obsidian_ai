# Incident Response

**Definition:** Incident response prepares for, detects, analyzes, contains and recovers from incidents while documenting decisions, notifying stakeholders and improving controls.

## Key points

- Events are observations; incidents involve threatened or realized security impacts.
- Containment and evidence preservation require coordination; phases overlap in real events.
- Preserve relevant logs, volatile state and chain of custody when legally/operationally needed.
- Investigate the entry path, affected assets, identity compromise, data access and corrective measures.

## AI security example

> [!example] Application
> If a prompt injection caused data exfiltration, preserve prompts/tool logs, revoke exposed tokens, block the path and verify integrity of the retrieval index.
