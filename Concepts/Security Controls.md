# Security Controls

**Definition:** A security control is a measure that reduces the probability or consequences of a threat.

## Key points

- Implementation categories: technical, managerial, operational, physical.
- Functional types: preventive, detective, corrective, deterrent, directive, compensating. Classify based on the context.
- A control must have an owner, an objective, test evidence, coverage limits and a process for exceptions.

## AI security example

> [!example] Application
> Document-level authorization is a technical preventive control; alerts on unauthorized queries are detective; disabling a compromised token is corrective.
