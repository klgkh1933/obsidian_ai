Domain one covers the AI life cycle, model types, and the underlying architecture of large language models. Let's get to work. Question one, machine learning types. A data scientist is training a model to identify fraudulent credit card transactions. They are using a data set where every transaction is already marked as either legitimate or fraud. What type of machine learning is being utilized? A unsupervised learning, B. Supervised learning, C. Reinforcement learning, D. Semi-supervised learning.

The answer B supervised learning. The logic the keyword is marked or labeled. When you provide the model with the answer key during training, it is supervised learning. Question two, neural network architecture. In a deep learning model, which layer is responsible for receiving the raw input data before it is processed by hidden layers? A output layer. B hidden layer. C input layer. D activation layer. The answer C input layer. The logic. All data enters the input layer. It is then weighted and passed through hidden layers where the learning happens before reaching the output layer for the final prediction. Question three. The transformer model. What specific mechanism allowed large language models, LLMs, to process entire sequences of text at once rather than one word at a time, leading to a massive leap in performance.

A back propagation. B. The attention mechanism. C. Gradient descent. D. Convolutional filters. The answer. B. The attention mechanism. The logic. Before transformers, AI read text left to right. The attention mechanism allows the model to look at every word in a sentence simultaneously to understand context. For example, knowing that it refers to the server in a long paragraph. Question four, the AI life cycle. Your team has finished training a model and is now deploying it to a production environment where it will process realworld user queries. What phase of the AI life cycle is the model currently in? A data preparation, B training, C inference, D hyperparameter tuning. The answer C inference.

The logic training is the learning phase. Inference is the execution phase. When the model is thinking and providing answers to users, it is performing inference. Question five, generative versus discriminative. A security tool uses AI to classify incoming emails as either spam or not spam. What category of AI model is this tool primarily using? A generative AI, B. Discriminative AI, C. Diffusion model, D. Gan, generative adversarial network. The answer B. Discriminative AI. The logic. Discriminative models classify or categorize data. Is it A or B? Generative models create new data, write a poem, or draw a picture. Question six. R A G. Retrieval augmented generation to reduce hallucinations and provide an LLM with access to your company's internal private documents.

Which architecture should you implement? A fine-tuning B. Rag retrieval augmented generation. C. Zeroshot prompting D. Model compression. The answer B. RAG. The logic. Rag allows the AI to look up facts in a trusted database before answering. It bridges the gap between the model's static training data and your live private data. Question seven, model errors. An LLM confidently provides a technical explanation for a software vulnerability that does not actually exist, citing fake CVE numbers. What is this phenomenon called? A. Overfitting. B underfitting. C. Hallucination. D. Poisoning. The answer. C. Hallucination. The logic. A hallucination occurs when a model generates a statistically probable but factually incorrect response. It sounds right, but it's a lie.

Question eight. Fine-tuning. You take a pre-trained LLM and perform additional training on a smaller specialized data set of medical records to make it an expert in healthcare terminology. What is this process called? A pre-training B fine-tuning C tokenization D quantization. The answer B fine-tuning. The logic fine-tuning is the act of taking a generalist model and turning it into a specialist by giving it a smaller focused data set. Question nine. Training pitfalls. A model performs with 99% accuracy on its training data but fails miserably when tested against new realworld data. What is likely wrong with the model? A. Underfitting. B. Overfitting. C. Data sparsity. D. High bias. The answer. B. Overfitting.

The logic. Overfitting means the model memorized the training data instead of learning the underlying patterns. It is too rigid to handle data it hasn't seen before. Question 10. Natural language processing. Before an LLM can process a sentence, it must break the text down into smaller numerical chunks that the computer can understand. What is this process? A. Vectorization, B. Tokenization, C. Embedding, D. Normalization. The answer. B. Tokenization. The logic. Tokenization turns words or parts of words into tokens.
