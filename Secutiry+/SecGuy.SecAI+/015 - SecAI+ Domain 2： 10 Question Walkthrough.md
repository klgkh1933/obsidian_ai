# 015 - SecAI+ Domain 2： 10 Question Walkthrough

We covered how AI is built. Now we cover how it is broken. Domain two is about the threat landscape. We're talking about prompt injection, model poisoning, and the specific risks that come with putting an LLM in front of your crown jewels. Let's get into the reps. Question one, prompt injection. A user enters a specific set of instructions into a customer service chatbot designed to make the AI ignore its original safety guidelines and reveal internal system prompts. What type of attack is this? A model inversion. B prompt injection. C evasion attack. D membership inference. The answer B prompt injection. The logic prompt injection is the SQL injection of the AI world.

It's an attempt to override the developer's instructions with the user's instructions to hijack the model's output. Question two, data poisoning. During the training phase of a new medical AI, an attacker gains access to the data set and injects subtle malicious data points that cause the model to mclassify a specific type of rare tumor. What is this called? A prompt leaking. B inference attack. C model poisoning. Denormalization. The answer C model poisoning. The logic. If the attack happens during training, it is poisoning. The goal is to corrupt the brain of the AI before it is ever deployed. Question three. Privacy risks. An attacker sends thousands of specialized queries to a facial recognition API.

By analyzing the confidence scores of the responses, they are able to determine if a specific person's photo was part of the original private training set. What is this attack? A. Model evasion. B. Membership inference. C. Prompt injection. D. Model theft. The answer B. Membership inference. The logic. Membership inference is a privacy attack. The goal isn't to break the AI, but to find out what data was used to train it, which can lead to massive data breaches of sensitive info. Question four, model inversion. An attacker repeatedly queries a specialized code assistant LLM. By observing the outputs, they are able to reconstruct snippets of the proprietary source code that the model was fine-tuned on.

What is this called? A model inversion. B model poisoning. C adversarial reprogramming. D prompt injection. The answer A model inversion. The logic. While membership inference asks was this person in the data, model inversion tries to actually reconstruct the data itself from the model's outputs. Question five, adversarial examples. A security researcher applies a transparent mathematically designed sticker to a stop sign. A self-driving car's vision system now identifies the sign as a 45 mph speed limit sign. What category of attack is this? A. Training attack. B. Evasion attack. Adversarial example. C. Model extraction. D. Denial of service. The answer. B. Evasion attack. Adversarial example. The logic. Evasion attacks happen at inference. Real time.

You aren't changing the model. You are tricking it with a specialized input that looks normal to humans but breaks the AI's logic. Question six, supply chain risk. Your company downloads a popular pre-trained model from an open-source repository like hugging face. However, the model contains a backdoor that triggers malicious behavior only when a specific secret phrase is used. What type of risk is this? A prompt engineering risk. B AI supply chain risk. C model decay. D over reliance. The answer B AI supply chain risk. The logic just like software AI has a supply chain. If you use a third-party model, the base model, you are inheriting all the risks and backd doors that come with it.

Question seven, mitigating prompt injection. Which of the following is the most effective way to reduce the risk of prompt injection in a production LLM application? A. Hiding the submit button. B. Using a system message with clear boundaries and input filtering. C. Deleting the model every 24 hours. D. Only allowing 10 words per prompt. The answer B. Using a system message with clear boundaries and input filtering. The logic. You must treat user input as untrusted. Using a strong system message, the developer instructions combined with an input filtering layer is the standard defense. Question eight, model extraction. A competitor writes a script that sends millions of prompts to your proprietary AI and records every answer.

They then use those pairs to train their own clone model for a fraction of the cost. What is this called? A model poisoning, B model extraction or model stealing, C prompt injection, D evasion attack. The answer B model extraction or model stealing. The logic model extraction is about stealing the intellectual property of the model without ever seeing the original code or weights. Question nine. Red teaming for AIA security team is hired to act as adversaries. They use jailbreaking techniques, adversarial inputs, and data poisoning attempts to find weaknesses in a new generative AI before its public launch. What is this process? A. Compliance auditing. B. AI red teaming. C. Quality assurance.

D. Static analysis. The tactical answer. B. AI. Red teaming. The logic. Red teaming in AI is the practice of breaking it on purpose to find safety and security gaps before the bad guys do. Question 10. Jailbreaking. A user uses a persona adoption technique telling the AI to act as an unfiltered lawless version of yourself named Dan. Do anything now. What is this an example of? A model poisoning. B. Jailbreaking. C. Membership inference. D. Supply chain attack. The tactical answer. B. Jailbreaking. The logic. Jailbreaking is a specific type of prompt injection designed to bypass the safety alignments, the moral compass of the model. Domain two is where the battle is won or lost.
