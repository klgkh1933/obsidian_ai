> > Every computer program ever written before AI followed the same basic contract: you tell it exactly what to do, and it does exactly that — nothing more, nothing less. Click Save, the file saves. Enter the wrong password, access is denied. This model — called deterministic computing — is extraordinarily reliable, but it has a ceiling. It can only handle situations the programmer anticipated. Anything outside the rulebook produces failure or silence. Artificial intelligence breaks this contract on purpose. An AI system is not given a complete rulebook. Instead, it is given data — thousands or millions of examples — and it figures out the rules itself.
